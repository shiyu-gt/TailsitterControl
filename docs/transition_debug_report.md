## 1. 调试背景

在阶段三（悬停PID联合调试）全部通过后，启动阶段四第1项——过渡飞行仿真（Transition Simulation）。目标为实现完整的**悬停（竖直）→ 平飞（水平巡航）→ 悬停回收**三段式飞行轨迹。

采用**增强型方案B**：外环由轨迹规划器直接给定期望俯仰角 `theta_des(t)` + 速度闭环修正；中环/内环复用 `HoverPID` 的姿态环与角速度环（通过 `q_desired_override` 注入期望四元数）。

## 2. 前向过渡（悬停 → 平飞）问题

### 2.1 现象

| 指标 | 初始状态（alpha限幅45°） | 修改后（alpha限幅90°） |
|------|------------------------|----------------------|
| 最大高度超调 | 较大（具体数值未记录） | **120 m** |
| 全程最大空速误差 | 可控范围 | **97.94 m/s** |
| 巡航段稳定性 | 基本可进入巡航 | 严重过冲，无法稳定巡航 |

### 2.2 根因分析

将 `aircraft_6dof.py` 中的 alpha 硬限幅从 `45°` 放宽至 `90°` 后，前向过渡严重恶化。原因在于：

- 前向过渡过程中，飞机在抬头状态下低速爬升，真实迎角可达 `40°~60°`。
- 当 alpha 限幅为 `45°` 时，超出部分被截断，气动模型使用的是截断后的外推数据，低头力矩和阻力被人为压低。
- 放宽至 `90°` 后，模型调用真实高迎角气动数据，该区间存在**强烈的低头恢复力矩和阻力**，导致：
  - 抬头困难，爬升率失控，高度过冲剧增；
  - 阻力剧增导致空速无法按预期建立，速度环持续输出低头指令，形成正反馈。

### 2.3 结论

**alpha 限幅 90° 不适合当前过渡任务**。当前过渡控制律与真实高迎角气动特性不匹配，截断至 `45°` 的模型虽然物理上不完全准确，但提供了可供控制器驾驭的近似环境。

**建议**：将 `aircraft_6dof.py` 第 512–513 行恢复为 `np.radians(45)`。

```python
# 恢复 alpha 限幅为 45°
alpha = self._apply_limit(alpha, np.radians(45), "alpha")
```

## 3. 回收过渡（平飞 → 悬停）问题【核心阻塞】

### 3.1 现象

回收段出现**灾难性失控**，典型仿真结果如下：

| 指标 | 数值 |
|------|------|
| 终点位置误差 | **504 m** |
| 终点空速 | **15 m/s** |
| 回收段最低俯仰角 | **-3.4°**（机头下俯） |
| 回收段俯仰角趋势 | 从 `28.5°` 持续下跌至负值 |

### 3.2 已尝试的修复策略及结果

| 策略 | 预期效果 | 实际结果 |
|------|---------|---------|
| 延长回收过渡时间至 `15 s` | 降低姿态变化率，减轻舵面负担 | **无效**，低头趋势未改善 |
| 提高速度环增益 `Kp_vel` | 加强速度跟踪，防止速度过低 | **无效**，甚至加剧振荡 |
| 两段式回收剖面（先减速再抬头） | 避免高速大迎角组合 | **无效**，抬头阶段仍失控 |
| 回收段限制 `max_throttle = 0.25` | 防止高度环过调导致下降 | **无效**，且导致额外掉高度 |
| 舵面限幅从 `20°` 放宽至 `30°` | 提供更大抬头力矩 | **无效**，30°仍不足以克服气动低头力矩 |
| alpha 限幅从 `45°` 放宽至 `90°` | 利用全量程气动数据 | **恶化**，高迎角低头力矩更强 |

### 3.3 根因分析：力矩平衡硬约束

回收过渡的本质矛盾在于**控制可用力矩 < 气动力矩需求**。

#### 3.3.1 高迎角下的气动低头力矩

根据 `aircraft_6dof.py` 中的气动插值数据（纵向力矩系数 `Cm`）：

| 迎角 alpha | 基准 Cm（无舵面） |
|-----------|----------------|
| `40°` | **≈ -0.13** |
| `50°` | **≈ -0.19** |

在回收过渡中，当飞机开始抬头、速度尚未充分降低时，迎角处于 `40°~50°` 区间。以典型过渡状态估算：

- 空速 `V ≈ 10~15 m/s`
- 空气密度 `ρ ≈ 1.225 kg/m³`
- 参考面积 `S ≈ 0.5 m²`（飞翼布局典型值）
- 平均气动弦长 `c_bar ≈ 0.3 m`

基准气动力矩（抬头为正）：

```
M_aero = Cm * q_inf * S * c_bar
       = (-0.13) * (0.5 * 1.225 * 12²) * 0.5 * 0.3
       ≈ -0.13 * 88.2 * 0.15
       ≈ -1.72 N·m
```

在 `alpha=50°` 时，该力矩可达 **≈ -2.5 N·m**。

#### 3.3.2 舵面可提供的最大抬头力矩

升降副翼（elevon）位于螺旋桨滑流中，使用滑流动压 `q_slip`。根据动量理论估算：

- 悬停滑流速度 `V_slip ≈ 25~30 m/s`
- 滑流动压 `q_slip ≈ 0.5 * 1.225 * 28² ≈ 480 Pa`

舵面气动效率（由 `aero.get_elevon_longitudinal_coefficients()` 测得）：

- `dCm/dde ≈ +0.0036 / deg`（即 `≈ +0.206 / rad`）

在 `de = 20°` 限幅下：

```
M_elevon_max = dCm * q_slip * S * c_bar
             = 0.0036 * 20 * 480 * 0.5 * 0.3
             ≈ **0.94 N·m**
```

即使放宽至 `de = 30°`：

```
M_elevon_max (30°) ≈ 1.4 N·m
```

#### 3.3.3 力矩缺口

| 状态 | 气动低头力矩 | 舵面最大抬头力矩 | 力矩缺口 |
|------|------------|----------------|---------|
| alpha=40°, V=12m/s | **-1.72 N·m** | +0.94 N·m (20°) | **-0.78 N·m** |
| alpha=50°, V=12m/s | **-2.50 N·m** | +1.40 N·m (30°) | **-1.10 N·m** |

**结论**：在回收过渡的高迎角阶段，即使舵面打满（30°），产生的抬头力矩也仅为气动低头力矩的 **55%~75%**。控制器无法克服这一物理硬约束，导致俯仰角持续下俯，飞机进入低头俯冲状态，最终远离目标轨迹。

> **这不是控制参数 tuning 问题，而是当前气动模型与舵面效率之间的固有不匹配。**

## 4. 可选的解决路径

基于上述分析，以下是突破回收过渡阻塞的几种策略，按侵入性从低到高排列。

### 方案一：轨迹重新设计 —— "先减速，后抬头"

**核心思想**：避免飞机在 **"尚有较高前向速度" + "需要大幅抬头"** 的组合下进入高迎角区。让飞机先在低迎角状态下充分减速，再执行大角度抬头。

**具体实现**：

1. 回收段分为两个子阶段：
   - **子阶段 A（减速期，t=20~28s）**：保持俯仰角在 `theta = 15°~20°`（略高于巡航，但远低于悬停），油门降低至接近悬停油门，利用重力和阻力减速，目标将空速降至 `5 m/s` 以下。
   - **子阶段 B（抬头期，t=28~35s）**：空速已低，再执行 `20° → 90°` 的俯仰角过渡。此时动压 `q_inf` 已大幅降低，气动低头力矩可能进入控制器可克服的区间。

2. 速度环在此策略中起关键作用：在子阶段 A，速度误差大，`theta_corr` 会自然压低 `theta_des`，防止过早抬头。

3. **风险**：减速期持续时间延长，水平位移增大，终点水平位置误差可能超标。需通过仿真验证。

### 方案二：调整气动模型 —— 降低高迎角低头力矩

**核心思想**：当前模型在 `alpha > 40°` 后的 `Cm` 曲线过于陡峭。对于尾座式无人机，高迎角悬停/过渡是核心工况，气动模型在此区间应呈现**中性稳定或弱静不稳定**（便于舵面控制），而非强静稳定（低头力矩过强）。

**具体实现**：

1. 审查 `aircraft_6dof.py` 中 `Cm(alpha)` 插值表的来源。若为基于常规固定翼飞机的 DATCOM/风洞数据，其高迎角特性通常不适用于尾座式垂直飞行。

2. 对 `alpha > 30°` 区间的 `Cm` 数据进行修正：
   - 将 `Cm(40°)` 从 `-0.13` 调整至 `-0.05`
   - 将 `Cm(50°)` 从 `-0.19` 调整至 `-0.08`

   使得舵面力矩（0.94 N·m）与气动力矩（约 -0.66 N·m）之比进入可控范围（约 1.4 倍裕度）。

3. **风险**：改变了飞机的基础静稳定性，需重新验证悬停稳定性（阶段三）。若 `Cm` 过于中性，悬停时可能增加姿态保持负担。

### 方案三：增强控制手段 —— 引入矢量推力或额外控制面

**核心思想**：当前仅有升降副翼提供俯仰力矩。若能增加额外的俯仰控制通道，可弥补舵面力矩不足。

**具体实现**：

1. **矢量推力/倾转旋翼**：若物理模型允许，在过渡段引入微小的螺旋桨倾转（如 `±10°`），推力矢量可直接产生俯仰力矩。这是真实尾座式无人机（如 Convair XFY-1）常用的过渡辅助手段。

2. **增加独立水平鸭翼/升降舵**：若模型结构支持，可在机头或机翼前缘增加小面积控制面，专门用于高迎角下的俯仰控制。鸭翼在失速前效率较高，且不受主翼流场分离影响。

3. **风险**：需修改 `aircraft_6dof.py` 的控制输入维度和气动力计算逻辑，工作量大。

### 方案四：降低过渡目标 —— 使用过渡友好的巡航工况

**核心思想**：既然从 `V=20 m/s` 直接回收至悬停存在力矩缺口，可降低巡航目标，使回收起始状态更靠近悬停。

**具体实现**：

- 将巡航速度从 `20 m/s` 降至 `10~12 m/s`
- 将巡航俯仰角从 `~5°` 提高至 `~20°`
- 这样回收过渡的俯仰角变化量从 `85°` 减少至 `70°`，且起始动压更低，气动低头力矩减小

**风险**：这相当于回避了高速巡航回收问题，不是根本解决。但对于当前仿真演示目的，可能是最快获得可接受结果的路径。

## 5. 推荐下一步行动

综合考虑工作量、风险和演示价值，建议按以下顺序执行：

### Step 1（立即执行）：恢复 alpha 限幅

将 `aircraft_6dof.py` 中的 alpha 限幅恢复为 `45°`，确保前向过渡回到基准状态。

### Step 2（高优先级）：实施"先减速后抬头"轨迹

修改 `transition_simulation.py` 的回收段逻辑：

1. 将回收段时长保持 `15 s`（已验证不足以解决问题，但为轨迹分段提供时间余量）。
2. 在回收前 `8~10 s` 内，让 `theta_ff` 仅缓慢抬升至 `20°`（而非直接往 `90°` 走），重点利用 `V_des` 的快速下降引导飞机减速。
3. 监控空速，当 `V < 5 m/s` 后再将 `theta_ff` 快速提升至 `90°`。
4. **移除或放宽回收段的 `max_throttle = 0.25` 限制**。该限制导致高度环无法有效维持高度，在减速期可能造成不必要的掉高度。若必须保留，应仅限制在抬头子阶段，而非整个回收段。

### Step 3（若 Step 2 仍失败）：微调高迎角 Cm

若即使充分减速后，抬头阶段仍因 `alpha=40°+` 的气动力矩而失败，则对 `Cm(alpha)` 在 `alpha > 35°` 区间的数值进行小幅软化（降低低头力矩幅度 30%~50%）。这是模型层面的合理修正，因为原始数据可能不适用于尾座式过渡工况。

### Step 4（长期）：评估是否需要额外控制面

若上述步骤均无法获得满足指标（终点误差 `<1 m`，终点速度 `<1 m/s`）的结果，则应在 `aircraft_6dof.py` 中引入额外俯仰控制自由度（如鸭翼或推力矢量），这是真实工程系统中解决该问题的标准做法。

## 7. 附录：力矩平衡验算代码片段

以下代码可用于快速验证特定状态下的力矩平衡：

```python
import numpy as np

# 参数（需根据 aircraft_6dof.py 实际值调整）
rho = 1.225
S = 0.5        # 参考面积 [m^2]
c_bar = 0.3    # 平均气动弦长 [m]
V_slip = 28.0  # 滑流速度 [m/s]
q_slip = 0.5 * rho * V_slip**2

# 气动数据（示例）
def Cm_base(alpha_deg):
    # 简化插值，实际应从 aero 对象读取
    if alpha_deg <= 30: return -0.02
    elif alpha_deg <= 40: return -0.13
    else: return -0.19

dCm_dde = 0.0036  # /deg

def max_elevon_moment(de_max_deg):
    return dCm_dde * de_max_deg * q_slip * S * c_bar

def aero_moment(alpha_deg, V):
    q_inf = 0.5 * rho * V**2
    return Cm_base(alpha_deg) * q_inf * S * c_bar

# 验算
for alpha_deg in [30, 40, 50]:
    for V in [8, 12, 15]:
        M_aero = aero_moment(alpha_deg, V)
        M_ctrl_20 = max_elevon_moment(20)
        M_ctrl_30 = max_elevon_moment(30)
        print(f"alpha={alpha_deg}°, V={V:2d}m/s | "
              f"M_aero={M_aero:+.2f} N·m | "
              f"M_ctrl(20°)={M_ctrl_20:+.2f} N·m | "
              f"裕度(20°)={M_ctrl_20+M_aero:+.2f} N·m")
```
